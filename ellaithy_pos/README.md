# Ellaithy POS 18.0.2.0.0
Standalone Odoo 18 POS / mini-ERP module.

Roles:
- Requester: create requests and see own orders.
- POS Operator: process all requested orders, receive/post payments, complete orders, see inventory/reports/charts.
- POS Admin: full configuration and administrative access.

Core masters: products, categories, customers, warehouses, payment methods.
Core operations: requests, approvals, processing, payments, sales/returns, stock movements, low-stock balances.
Analytics: sales, products, payments, stock movement pivot reports and charts.
